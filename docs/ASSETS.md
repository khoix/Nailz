# Asset manifest — E1

All visible meshes and materials are authored procedurally in `src/scene/createScene.ts`. No downloaded model, image, texture, sound, font, or music asset is bundled. System fonts are used. Three.js is an npm dependency with its own MIT license in the package.

E1 shapes are intentional prototypes. E4 replaces/polishes hero geometry and adds carnival scenery; E5 supplies the operator. Record source, license, changes, and location here for each later external asset.

Music: user-provided later; no placeholder or generated music.
